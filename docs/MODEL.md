# 器件方程、离散与误差的含义

## 坐标、接触与准费米能级

P 接触在左，N 接触在右，正方向从 P 指向 N。输入偏压 V 表示 P 相对 N 的电压；代码将 P 接触外加电势保持为零，N 接触外加电势设为 -V。两端均采用理想欧姆接触，载流子保持当地电中性值。

长度内部为 m，浓度 m⁻³，电流密度 A/m²，复合率 m⁻³/s。输入掺杂 cm⁻³ 乘 1e6；输入几何 μm 乘 1e-6。本征浓度采用室温 1e10 cm⁻³ 标定的温度关系，迁移率分别固定为 1350、480 cm²/(V s)，扩散系数通过 Einstein relation（爱因斯坦关系）D=mu*VT 计算。

定义无量纲变量：

```math
u=\psi/V_T,\quad n=n_i e^{u+a},\quad p=n_i e^{-u+b},\quad V_T=k_BT/q.
```

a、b 是活动度的对数。以 P 接触平衡费米能为零，硅本征能级近似为 Ei=-psi eV，电子与空穴的 Quasi-Fermi energy（准费米能量）为：

```math
F_n=V_Ta,\qquad F_p=-V_Tb\quad\mathrm{(eV)}.
```

这与准费米“电势”的符号不同。正向 V 时，N 接触的 Fn=Fp=V eV；P 接触均为零。平衡时 a=b=0，两个能级处处重合。质量作用关系为：

```math
np=n_i^2\exp[(F_n-F_p)/V_T].
```

接触无量纲电势为：

```math
u_P=-\operatorname{asinh}(N_A/2n_i),\qquad
u_N=\operatorname{asinh}(N_D/2n_i)-V/V_T.
```

接触 a 从 0 到 V/VT，b 从 0 到 -V/VT。掺杂过渡是固定物理宽度的 tanh 曲线，不随网格改变，从而让独立配点和网格研究比较同一个连续问题。

## 连续方程

```math
-\varepsilon\psi''=q(p-n+C),\quad E=-\psi',\quad
J_n=q\mu_n nE+qD_n n',\quad J_p=q\mu_p pE-qD_p p'.
```

```math
J_n'=qR,\qquad J_p'=-qR.
```

净复合率 R>0 表示复合，R<0 表示产生。中间禁带陷阱且电子/空穴寿命相同为 tau 时，SRH（Shockley-Read-Hall，陷阱辅助复合）模型为：

```math
R=\frac{np-n_i^2}{\tau(n+p+2n_i)}.
```

主程序用 ni²*expm1(a+b) 求分子，以保持平衡零复合并减小相消。该模型不包含辐射、Auger、雪崩或隧穿。

## Scharfetter-Gummel 通量

令相邻节点无量纲电势差为 du，间距 h，Bernoulli function（伯努利函数）B(z)=z/(exp(z)-1)。SG 在边上积分线性电势下的漂移-扩散关系，得到：

```math
J_n=\frac{qD_n}{h}[n_R B(du)-n_L B(-du)],\qquad
J_p=\frac{qD_p}{h}[p_L B(du)-p_R B(-du)].
```

平衡玻尔兹曼浓度应使两种通量各自为零。B 在零点采用级数，在大参数处使用安全形式；不能直接把 0/0 或溢出的 exp 带进求解器。

以 A=exp(a)、Bact=exp(b) 作为活动度，同一通量可写成：

```math
J_{n,e}=g_{n,e}(A_R-A_L),\qquad
J_{p,e}=-g_{p,e}(Bact_R-Bact_L).
```

导纳 gn、gp 包含局部电势和 SG 伯努利函数。代码的 `conductances` 给出精确系数。这里的 Bact 与伯努利函数 B 不同。

## Gummel 自洽迭代

先固定活动度，使用解析三对角雅可比与阻尼牛顿法求非线性泊松方程；再固定电势，通过正系数三对角连续性系统更新电子与空穴活动度。SRH 分母与另一种载流子在子步中冻结/更新，以半隐式形式处理。对数活动度混合保持正浓度。偏压续接的内部最大步长为 0.025 V。

外层无量纲更新低于 2e-9 后，再求一次泊松方程并评估通量一致性。泊松子问题残差阈值为 2e-10。外层小更新只能说明所实现迭代的稳定性，还必须结合构成关系、独立参考和网格检查。

## 为什么另外提供积分电流求值？

中性区的大浓度变化很小，直接相减得到的原始边电流可能出现明显的相对浮点误差。代码保留它们为 Jn_raw/Jp_raw，同时从同一个 SG 离散方程计算稳健通量。

令内部节点复合源积分为 Si=q*Ri*控制区间长度，从左接触累计至边 e 为 Ke。离散连续性给出：

```math
J_{n,e}=j_{n,0}+K_e,\qquad J_{p,e}=j_{p,0}-K_e.
```

两端活动度之差又满足各边电流/导纳的总和，因此可以解出 jn,0 和 jp,0。这个积分式没有引入理想二极管公式，也没有任意选择一个电流常数。将这些通量从两端反积分，可重建 A、Bact；其对数应与求解活动度一致。基准误差约 9.14e-10。

总电流恒定在这种形式下是结构性质；它不是独立验证。原始电流诊断、活动度重建、配点参考、网格加密与解析极限共同提供证据。

## 配点参考及一次有用的数值失败

参考支路将电势、电势导数、两种 ni 归一化浓度和两个电流写成六个连续一阶方程，由 SciPy `solve_bvp` 的自适应配点法求解。SG 剖面只作为初值；收敛和网格由另一套算法控制。默认相对 RMS 方程残差目标为 2e-6，不是电流误差的严格界。

最初若对参考支路也使用 log(n)、log(p)，理想接触处的极小少数载流子与注入剖面会产生很薄的对数层，增加刚性甚至导致失败。改为 ni 归一化的直接浓度后，接触变化可被可靠表示。参考结果还检查最终浓度为正。这个例子说明“使用对数变量”也要结合方程形式判断。

独立性仅针对离散与方程实现；材料、边界和参数相同，初值来自主解。两套方法都可能共享物理模型偏差，因此不能视为与实验的一致性证明。

## 理想因子、解析极限与反演

表观理想因子定义为 n_app=1/(VT*d ln J/dV)。只对正向正电流计算，省略数值微分端点。有限偏压、混合电流与有限基区会使结果偏离理想的整数值；图中没有把指数斜率手动设成 1 或 2。

无复合、低注入解析对照采用两侧有限中性长度与耗尽边界估计。它不完全包含平滑结与连续空间电荷分布，因此作为近似极限比较；基准 0.1-0.4 V 内差异约 0.4%-0.6%。

寿命反演的“观测”由配点法生成并加对数噪声；逆模型使用 301 点 SG 网格，只拟合共同 tau。掺杂、迁移率、几何、温度与接触保持已知。单个种子误差和局部线性化不确定度不能替代模型失配、未知接触或多参数可辨识性分析。
