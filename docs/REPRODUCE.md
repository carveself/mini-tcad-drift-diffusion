# 第三阶段复现路线

先保留参考版本，再在自己的分支中逐步重写。完成标准是能够解释和修改方程、定位失败、重新验证，不只是运行已有脚本。

## 0. 建立基准

按主 README 安装后，运行 `python run_all.py` 与 `python -m unittest discover -s tests -v`。应该得到 8 张主图、13 项通过的测试、验证 JSON 和明确标记的合成数据。

记录环境版本；注意电流密度 J 与实际电流 I 的面积换算。基准主网格 601 点，反演网格 301 点；不要把更换网格后的结果与旧报告中的数字混用。

## 1. 平衡自洽解

```bash
python src/stages.py equilibrium --output reproduction/01-equilibrium
```

从体区电中性推导接触的 asinh 电势。自己检查 n*p=ni²、两条准费米能重合、两种原始电流均为零以及 R=0。基准内建势约 0.714317 V。

需要解释：为什么电场不为零时，净电流仍可以为零？答案应同时涉及漂移与扩散，而不是只说“平衡所以为零”。

## 2. 推导并重写 SG 边通量

阅读 `bernoulli` 和 `conductances`，从一条边上的漂移-扩散方程推导 SG。检查 B(0)=1 和 B(-z)=exp(z)*B(z)。先用平衡玻尔兹曼浓度检验零通量，再接入连续性方程。

动手实验：在自己的分支尝试直接中心差分通量与 SG 比较，记录网格、电势跳变和是否出现非正浓度。恢复基准代码，不把未通过验证的试验结果混进正式数据。

## 3. 加偏压与两种准费米能

```bash
python src/stages.py biased --output reproduction/02-biased
```

这个检查点为 301 点、0.2 V，J 约为 0.1390834 A/m²；主报告用 601 点，约为 0.139062 A/m²。差别是网格误差，不是程序随机变化。

逐行解释 P/N 接触的 u、a、b。以 eV 画图时，Fn=VT*a，Fp=-VT*b；正向偏压 V 下，右接触两者均为 V eV。通过 n*p 与 Fn-Fp 的关系核对符号。

## 4. 加 SRH 与验证稳态守恒

比较开关 `Diode(recombination=False)` 与默认 SRH 模型。检查反向结中心 R<0，正向 R>0；解释电子电流增长、空穴电流下降而总电流不变。

重写积分电流公式，并从通量反积分活动度。图中原始局部 SG 电流在低电流下可能有浮点波动；必须同时展示原始诊断和重建误差。总电流平坦是结构性质，独立验证还要靠后续步骤。

## 5. 独立配点与网格收敛

```bash
python src/stages.py experiments --output reproduction/03-experiments
```

阅读 `collocation_reference.py`，列出六个一阶方程与六个边界条件。说明 SG 只提供初值，配点法重新求连续方程。复现五个偏压对照与四级网格；在 0.45 V 处应看到接近二阶误差下降。

动手：把配点法容差调紧，检查参考值是否稳定；再改变 Gummel 混合比例和偏压路径。只调整迭代参数时，收敛解应一致。

## 6. 用寿命解释理想因子

查看 1 ns、10 ns、100 ns 的结果。把局部对数斜率与电流来源联系起来；不要求曲线刚好等于 1 或 2。先预测缩短寿命对结内复合和低正向电流的影响，再运行验证。

作为自己的扩展，可改变结过渡宽度或接触距离。必须固定其余参数、保留网格检查，并解释有限基区为何影响解析近似。不要同时改多个条件后只归因于一个变量。

## 7. 合成数据寿命反演

```bash
python src/stages.py extract --output reproduction/04-extraction
```

12 个观测点为独立配点法生成的合成数据，对数噪声标准差 0.02。默认真实寿命 8 ns，得到约 7.99294 ns。你需要说明已知参数、数据生成模型、逆模型、拟合目标、初值与误差的条件性。

动手：更换种子、增加噪声、改变电压覆盖范围，或故意用错迁移率。记录寿命偏差，比较随机误差与系统模型误差。只有确实完成这些实验后，才能把它们写作自己的扩展贡献。

## 8. 准备口述材料

使用 `INTERVIEW.md` 的练习结构，准备能脱离图像讲清楚的问题。最后形成一页个人实验日志：重写过的函数、一次失败、修复证据、一个扩展实验和模型局限。

整个路线建议按数周学习安排，不以脚本运行速度代替理解。参考实现与 AI 协助的部分应按实际情况说明。
