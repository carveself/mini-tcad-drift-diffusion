## 0:00-0:35 问题与进阶

我复现了一个一维 PN 结漂移-扩散模型，研究 SRH 复合寿命如何影响电流与局部理想因子。项目从平衡静电学推进到非平衡输运，同时求电势、电子与空穴，电流来自器件方程。器件是平滑掺杂的硅同质结，两端采用理想欧姆接触。

## 0:35-1:20 方法

泊松方程约束电荷与电势，电子和空穴连续性方程约束电流与复合。我使用 SG 边通量与 Gummel 迭代，配合正活动度变量、阻尼牛顿子问题和偏压续接。非平衡下两种准费米能可以分离，接触符号通过浓度关系核对。

## 1:20-2:05 验证

总电流平坦是结构性质，因此我还用不同的连续方程配点离散、四级网格和低注入解析极限检查。五个对照偏压的最大电流差异约为 0.0072%，网格误差接近二阶。局部大数相减会使低电流有浮点噪声，所以我从同一 SG 系统的积分约束求电流，并反积分重建活动度检查一致性。

## 2:05-2:40 结果与可研究的问题

寿命改变了复合与扩散的相对贡献，表观理想因子随偏压变化。另用配点法生成合成数据，加约 2% 对数噪声，再由 SG 模型提取共同寿命。默认 8 ns 算例提取约 7.993 ns；这是已知几何和材料条件下的合成验证，不是实测精度。

## 2:40-3:00 局限与个人贡献

模型使用固定迁移率、经典统计和理想接触，未包含速度饱和、自热和击穿。请在此处加入自己实际完成的一次修改、失败与验证证据；例如噪声区间、接触距离或迁移率设错导致的提取偏差。参考实现与自己重写的部分应明确区分。

## 英文简介练习

I reproduced a one-dimensional silicon diode solver based on the drift-diffusion equations. The model couples Poisson's equation with electron and hole continuity equations and includes Shockley-Read-Hall recombination. I used Scharfetter-Gummel fluxes and Gummel iteration, then checked the results with adaptive collocation and mesh refinement. A synthetic inverse experiment estimates a common carrier lifetime. The main limitations are classical statistics, constant mobility and ideal contacts.

## 追问与回答要点

| 问题 | 回答方向 |
| --- | --- |
| 前两个项目到这一步多了什么？ | 非零偏压连续性方程与电流输运；准费米分离；复合/产生；多方程自洽 |
| SG 为什么能保持平衡零电流？ | 它对边上的漂移-扩散关系积分，伯努利函数满足与玻尔兹曼浓度相容的恒等式 |
| 为什么两种电流不分别守恒？ | 它们通过相反符号的 qR 相互转换；稳态无外部光生源时总电流仍恒定 |
| 总电流恒定能证明正确吗？ | 不够。还要检验活动度重建、连续方程配点、网格与解析极限 |
| 准费米能与电势的符号？ | Ei=-psi，Fn=VT*a，Fp=-VT*b；用 n、p 的玻尔兹曼关系推导 |
| 为什么低偏压理想因子也不一定等于 2？ | 有有限偏压的减一项、混合电流、场和复合分布等影响，局部斜率不是预设常数 |
| 配点法到底独立在哪里？ | 连续 ODE 实现与自适应离散不同；物理模型相同，初值来自 SG，不能声称与实验独立一致 |
| 电流积分会不会只是人为拉平？ | 积分值同时满足离散连续性和两端活动度约束，还能重建节点活动度；原始局部值保留用于比较 |
| 为何参考支路不全用对数浓度？ | 理想接触的少数载流子会产生很薄的对数层；直接浓度配合 ni 归一化更适合该参考 BVP |
| 寿命能当陷阱密度直接报告吗？ | 不能。还需要俘获截面、陷阱能级等信息，这里只有一个共同有效寿命 |
| 如何理解 0.088%？ | 单个固定种子、已知其他参数的合成提取误差，不是实测或普遍保证 |
| 哪部分是你自己的工作？ | 指向真实复现、重写、排错和扩展记录，说明参考实现与工具协助来源 |
